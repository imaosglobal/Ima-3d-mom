# IMA - Global Adaptive System

A unified AI system combining:
- Chat interface
- Learning engine
- Commerce layer
- Global API

## Modules
- api: user interaction
- brain: learning & evolution
- commerce: store & dropshipping
- system: orchestration

## Vision
A single adaptive system that learns from users and improves continuously.
